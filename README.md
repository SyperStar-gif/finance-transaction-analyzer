# FinPulse — Финансовый скилл ИИ-агента (Financial Transaction Analyzer & ML Classifier)

Комплексный финансовый скилл (`finance-transaction-analyzer`) и аналитическая панель управления для ИИ-агентов. Обеспечивает автоматическую классификацию банковских транзакций с применением алгоритмов машинного обучения (Multinomial Naive Bayes + TF-IDF взвешивание токенов + MCC-коды + гибридный контур Gemini API), генерацию ежемесячных отчётов с визуализацией, контроль бюджетных лимитов с уведомлениями, безопасную интеграцию с банковскими API (Open Banking / ISO 20022) и автономную работу в офлайн-режиме с детерминированной синхронизацией.

---

## Основные возможности

1. **ML-классификация транзакций и активное дообучение (Online Learning)**
   - **Модель**: Multinomial Naive Bayes с TF-IDF взвешиванием морфологических основ (стемминг русского и английского языков), сглаживанием Лапласа и учётом банковских MCC-кодов (`5411`, `5812`, `4121`, `4900`, `5912`, `5311`, `3011` и др.).
   - **Активное обучение**: При ручной корректировке категории пользователем модель мгновенно пересчитывает апостериорные веса токенов и MCC (`retrainModelWithSample`), повышая точность распознавания схожих мерчантов.
   - **Серверный гибридный контур**: Поддержка глубокого семантического разбора сложных чеков через серверный маршрут `/api/skill/classify-ai` (`@google/genai`, модель `gemini-3.8-flash`) с автоматическим переключением на локальное ядро при отсутствии сети.

2. **Генерация ежемесячных отчётов и визуализация**
   - Расчёт совокупных расходов, доходов, чистого денежного потока (Net Cashflow), нормы сбережений (Savings Rate) и среднего чека.
   - Сравнение динамики месяц-к-месяцу (MoM Delta %) по каждой категории расходов.
   - Визуализация распределения затрат по категориям, кривой ежедневных трат и рейтинга крупнейших мерчантов.
   - Экспорт аналитических сводок в форматах `CSV` и `JSON`.

3. **Лимиты бюджета и система уведомлений**
   - Индивидуальная настройка месячных лимитов и порогов предупреждения (например, `80%` — предупреждение, `100%` — превышение лимита) для каждой категории.
   - Автоматическая генерация уведомлений с точным расчётом суммы превышения или остатка бюджета.

4. **Интеграция с банковскими API (Open Banking)**
   - Поддержка коннекторов: **Т-Банк Open API**, **Сбер ID / Финансовый API**, **Альфа-Банк Open API**, **Райффайзен Банк API**.
   - Защищённый обмен по стандартам `OAuth 2.1 + mTLS`, `OpenAPI FAPI 2.0`, `TLS 1.3 / AES-256-GCM`.
   - Автоматическая нормализация входящих банковских выписок, дедупликация по контрольным суммам (`FNV-1a Checksum`) и потоковая ML-разметка.

5. **Офлайн-режим и синхронизация без конфликтов**
   - Локальное хранилище состояния (`localStorage` + очередь операций `OfflineQueueItem`).
   - В офлайн-режиме все новые транзакции, перекатегоризации и изменения лимитов записываются в очередь синхронизации с криптографическим отпечатком (`chk_*`).
   - При восстановлении соединения выполняется идемпотентная синхронизация с разрешением дубликатов и дообучением ML-модели.

## Архитектура проекта

```text
/
├── README.md                                      # Документация проекта и руководство по запуску
├── skill.config.json                              # Итоговый файл конфигурации финансового скилла и зависимостей
├── package.json                                   # Манифест пакетов Node.js, скриптов сборки и проверок
├── server.ts                                      # Express + Vite сервер с API-маршрутами (/api/skill/*, /api/bank/*)
├── skills/
│   └── finance-transaction-analyzer/
│       └── SKILL.md                               # Спецификация скилла для подключения к ИИ-агенту
└── src/
    ├── App.tsx                                    # Главный интерфейс управления скиллом и финансовой аналитики
    ├── index.css                                  # Конфигурация Tailwind CSS v4 и табличной типографики
    └── lib/
        ├── financeSkill.ts                        # Ядро ML-классификатора, отчётов, лимитов и офлайн-синхронизации
        ├── financeSkill.test.ts                   # Модульные тесты (node:test) для проверки всех алгоритмов
        └── skillDocs.ts                           # Встроенные спецификации конфигурации и манифестов
```

## Проверка компонентов и запуск

### 1. Установка зависимостей
```bash
npm install
```

### 2. Запуск модульных тестов ML-ядра и синхронизации
```bash
node --test src/lib/financeSkill.test.ts
```

### 3. Проверка типов и сборка проекта
```bash
npm run lint
npm run build
```

### 4. Запуск сервера разработки (Full-Stack Express + Vite на порту 3000)
```bash
npm run dev
```
