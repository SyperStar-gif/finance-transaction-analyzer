# Скилл агента: Анализ финансов и ML-классификация транзакций (`finance-transaction-analyzer`)

Данный скилл предоставляет ИИ-агенту детерминированные инструменты и модели машинного обучения для управления личными и корпоративными финансами.

## 1. Вызываемые функции скилла (Agent Tool Declarations)

### `classifyTransactionML(model, input)`
Классифицирует транзакцию по названию мерчанта, назначению платежа, сумме и MCC-коду.
- **Алгоритм**: Multinomial Naive Bayes с TF-IDF взвешиванием основ слов и байесовскими априорными весами MCC-кодов.
- **Выход**: `categoryId`, `confidence` (`0.00..0.99`), распределение вероятностей по всем 10 категориям и список совпавших признаков (`matchedFeatures`).

### `retrainModelWithSample(model, sample)`
Выполняет онлайн-дообучение модели на основе пользовательской корректировки категории (`Active Learning`).

### `generateMonthlyReport(transactions, month)`
Формирует ежемесячный аналитический отчёт за период `YYYY-MM`:
- Общие расходы, доходы, чистый денежный поток (`netCashflow`) и норма сбережений (`savingsRatePercent`).
- Детализация по категориям с расчётом доли (`sharePercent`) и динамики к прошлому месяцу (`momDeltaPercent`).
- Ежедневный ряд расходов (`dailySeries`) и топ мерчантов (`topMerchants`).

### `evaluateBudgets(transactions, budgets, month)`
Проверяет соблюдение установленных месячных лимитов по каждой категории и формирует уведомления при достижении порога предупреждения (`warningThresholdRatio`, по умолчанию `80%`) и при превышении лимита (`100%`).

### `synchronizeOfflineQueue(transactions, budgets, queue, mlModel)`
Выполняет пакетную синхронизацию операций, накопленных в офлайн-режиме (`CREATE_TRANSACTION`, `UPDATE_CATEGORY`, `UPDATE_BUDGET`), с дедупликацией по детерминированной контрольной сумме `chk_*`.
